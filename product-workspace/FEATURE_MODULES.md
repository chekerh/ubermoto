## Feature modules (and free vs paid mapping)

### Core marketplace (free for customers)
- Catalog browse/search
- Cart + checkout + order creation
- Delivery tracking + notifications
- Order history + reorder

### Driver module (free, with optional future upsell)
- Registration + verification docs
- Availability + job lifecycle
- Earnings + payouts records

### Merchant module (paid)
**Basic (paid)**
- Merchant profile
- Catalog management (products/categories)
- Order management (status updates, preparation times)
- Basic analytics (orders/day, revenue, cancellations)

**Pro (higher paid)**
- Promo campaigns + coupons
- Advanced analytics (cohorts, repeat rate, top SKUs)
- Dynamic storefront blocks (hero banner, featured categories)
- Priority support SLA

### Admin & operations (internal only)
- Driver/document review queue
- Support ticket queue + macros
- Content/settings CMS (pricing, announcements, FAQ)
- Feature flags & rollout controls
- Billing event viewer + audit logs

### Observability & security (always-on)
- Health checks, system version
- Rate limits
- Audit logging for sensitive actions
- Webhook idempotency

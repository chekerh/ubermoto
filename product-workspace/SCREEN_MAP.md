## Screen map (v1)

### Shared
- Splash + language select
- Login / register (customer/driver)
- Settings (profile, notifications, language, theme)
- Support (FAQ, create ticket, tickets list)

### Customer
- Home (featured merchants/products, search, categories)
- Product details
- Cart
- Checkout (address select, promo code apply, fee breakdown)
- Order confirmation
- Orders list + order details
- Live delivery tracking map

### Driver
- Driver dashboard (online/offline, job list)
- Job details + status actions
- Navigation / map view
- Document upload + verification status
- Earnings + payouts history

### Merchant (paid web/app dashboard)
- Merchant overview (orders, revenue, delivery metrics)
- Catalog management (products, categories)
- Promotions/campaigns
- Operations settings (hours, regions, surge participation)
- Billing (plan, invoices, manage subscription)

### Admin (internal)
- Admin dashboard (KPIs)
- Review queues (drivers, documents)
- Users (search/debug)
- Content/settings (pricing plans, FAQs, announcements, feature flags)
- Support queue
- Surge rules + promo codes management
- Webhook events + audit log viewer
